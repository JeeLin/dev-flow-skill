# 步骤3：开发（处理待办事项）

## GUARD

- 前置状态：步骤2 已勾选，Flow Status 步骤3 未勾选
- 幂等：子任务与 bug 处理本身按状态列（⬜/✅、⬜/[x]）续做，已完成的不重做

## ACT

1. 读取里程碑文档中的子任务清单、详细设计和 Bugs 表格
2. 先处理所有子任务（按详细设计实现代码，每个子任务完成后更新状态 ⬜ → ✅ 并提交）
3. 所有子任务完成后，检查 Bugs 表格
4. 按优先级处理 bug：🔴 → 🟡 → 🟢（🟢 同样已登记入本表，一并处理）
5. 每个 bug 处理完后，在文档中勾选 [x] 并提交
6. 重复 4-5 直到所有 bug 处理完毕
7. 满足门禁后进入 MARK

**处理顺序**：先完成所有子任务（子任务完成后，某些 bug 可能已不存在），再按优先级处理剩余 bug。

**原则**：每个 commit 只包含一个子功能点或一个 bug 修复；实现每个子任务后立即提交；修复每个 bug 后立即提交；不做文档外的大功能。

## MARK

- 勾选 Flow Status 步骤3（此后状态机按审查轮状态行进入步骤4）

## 门禁

所有子任务标记为 ✅ 且 Bugs 表格中无 ⬜ 行（🔴/🟡/🟢 均需处理）。

# mdflow 产出文档禁用字元表（繁体/异体）
#
# 用途：scripts/check.sh 做码点级扫描，拦截 mdflow 会话写文档时的简繁混写污染。
# 格式：每行一个字元，`#` 之后为注释（扫描时整行忽略，故注释可写简体对照）。
#
# 选取原则（精简表，不追求覆盖全部繁体）：
#   1. 真实语料复现——优先收录消费者 .mdflow 文档中实际出现过的繁体字元；
#   2. 锚点词汇——收录 mdflow 契约锚点词（审查/步骤/报告/台账/候选/契约…）的繁体形，
#      这类字元写错会直接破坏 grep 门禁（如 C5 抓 `### 沉淀候选格式`）。
#
# 不收录（避免误报）：
#   - 简繁同形的合法简体字（面/干/后/里/台/系/只/云/范/采/舍/钟/丑/谷/姜/折/志…）；
#   - 简体与繁体同形近义但两字皆合法的对（复↔複↔覆、准↔準、划↔劃、丑↔醜…）中的简体侧；
#   - 形近错字（淺/慨/混 等本身是合法简体字，全局禁会误伤「混乱/感慨」）——
#     这类由「锚点字节校验」单独兜底，不进本表。
#
# 维护：新增条目须能在真实语料中复现，或属锚点词汇的繁体形；
#       改本表须同步 check.sh 的 C6 规则计数（不涉及，见 C6 只读表本身）。
